# MediSlot — Smart Hospital Appointment Booking System

MediSlot is a high-performance, real-time hospital appointment booking system built with Flask, SQLAlchemy, and Socket.IO. It features smart doctor recommendations, real-time queue tracking, and a premium admin dashboard.

## Features
- **Smart Scheduling**: Recommends slots based on doctor availability and patient department.
- **Real-Time Queue**: Patients see their live queue position and estimated wait time without page refreshes.
- **Admin Dashboard**: Live activity feed and dynamic slot grid for staff.
- **Secure Auth**: OTP-based verification for patient registrations.
- **Responsive Design**: Premium UI built with Tailwind CSS.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Initialize DB: `python init_db.py`
3. Run: `python app.py`
